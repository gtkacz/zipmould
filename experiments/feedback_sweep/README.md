# Exploratory feedback sweep

The confirmatory study (`paper/`) found that the configured edge-feedback
package changed solve probability by +1.29 points on the sealed test set, and
its Discussion could not say whether feedback is inert or merely
miscalibrated. This sweep asks that question on public data only. Nothing here
is confirmatory, and the released Challenge v1 test set is never read.

Each full-feedback variant overrides the frozen configuration
(`configs/challenge/v1-confirmatory.toml`) and is paired, puzzle by puzzle and
seed by seed, with the feedback-frozen arm at the same population and iteration
cap. The estimand, stratified puzzle bootstrap (10,000 replicates, SplitMix64
seed 20260716) and ±5-point band are those of the frozen protocol.

```bash
uv run python -m experiments.feedback_sweep.run --split dev
```

Removing edge replacement noise and raising the feedback weight from
α = 0.318 to about 1 turns a near-null contribution into a large one. The
two knobs interact: α = 1 with the frozen noise level hurts, and the effect
of α at z = 0 is an inverted U. These dev intervals ignore that the best of
17 variants was picked from the same data.

## Held-out replication plan (fixed before any train run)

The public train split (200 puzzles, 40 per stratum) has never been used for
generator calibration, stratum selection or solver configuration.

- Primary: `full-z0-alpha1` (z = 0, α = 1, every other value frozen) against
  `frozen`, 64 iterations of 53 walkers, seeds 0–29, global seed 0.
- Estimand, interval and classification: as in the frozen protocol.
- Prediction: *helpful*, with the whole 95% interval above +5 points. The dev
  estimate of +21.07 points was the maximum of 17 variants and should shrink.
- Secondary: `full` (the confirmatory configuration) against the same frozen
  arm, as a third estimate of the configured package.
- Both results are reported whatever they show.

```bash
uv run python -m experiments.feedback_sweep.run --split train --variants frozen full full-z0-alpha1
```

This plan is committed to Git before the run; like the confirmatory protocol,
it is not registered with an external service.

## Held-out replication result (train, 200 puzzles × 30 seeds)

`out/train/summary.json`.

| Variant | Full | Frozen | Difference, points (95% interval) | Classification |
|---|---:|---:|---:|---|
| full-z0-alpha1 | 0.607 | 0.401 | +20.63 (+17.45, +24.00) | helpful |
| full | 0.423 | 0.401 | +2.22 (+0.98, +3.48) | practically equivalent |

The prediction held: the recalibrated update is helpful on puzzles that played
no part in choosing it, with little shrinkage from its dev estimate. The
confirmatory configuration again lands inside the band.

By stratum, the recalibrated gain ranged from +11.2 to +29.2 points on dev and
from +12.3 to +28.3 points on train, positive in all five strata on both
splits and larger where the frozen arm solved less often.

## Re-tuned stateless constructor (dev search, then a second plan)

The recalibration above changed only values the frozen arm ignores, so its
gain is measured against a stateless constructor whose heuristic weights were
inherited from legacy full-feedback tuning. `tune.py` re-tunes that
rival on dev: 48 weightings of β, γ_man, γ_warns and γ_par (legacy ranges;
γ_art cancels for surviving moves), the unchanged weights included, each run
frozen on 100 dev puzzles × 5 seeds at the same 3,392-path budget.

```bash
uv run python -m experiments.feedback_sweep.tune --arm frozen
```

The best weighting (`out/tune-frozen/search.json`, candidate 7: β = 2.756,
γ_man = 0.195, γ_warns = 2.059, γ_par = 1.120) solved 0.698 of dev runs against
0.458 for the unchanged weights, which is more than the recalibrated feedback
variant reached on dev (0.659 at 30 seeds). It was the best of 48 on five
seeds, so this is an optimistic estimate.

### Second held-out plan (fixed before the run)

On the same 200 train puzzles and seeds 0–29, run `frozen-tuned` (weights
above, update frozen), `full-tuned` (same weights, confirmatory feedback
values) and `full-tuned-z0-alpha1` (same weights, z = 0, α = 1), and report:

- A: `full-z0-alpha1` (inherited weights) against `frozen-tuned`. Prediction:
  not *helpful*; the re-tuned stateless constructor matches or beats the
  recalibrated feedback variant.
- B: `full-tuned-z0-alpha1` against `frozen-tuned`. No directional
  prediction: α = 1 was chosen against β = 0.735, and the tuned β is larger.
- C: `full-tuned` against `frozen-tuned`. Prediction: practically equivalent.

```bash
uv run python -m experiments.feedback_sweep.run --split train --variants frozen-tuned full-tuned full-tuned-z0-alpha1
```

### Second held-out result (train, 200 puzzles × 30 seeds)

| Comparison | Full | Frozen | Difference, points (95% interval) | Classification |
|---|---:|---:|---:|---|
| A: full-z0-alpha1 vs frozen-tuned | 0.607 | 0.711 | −10.37 (−14.08, −6.47) | harmful |
| B: full-tuned-z0-alpha1 vs frozen-tuned | 0.756 | 0.711 | +4.55 (+2.15, +7.12) | inconclusive |
| C: full-tuned vs frozen-tuned | 0.727 | 0.711 | +1.67 (+0.75, +2.65) | practically equivalent |

Predictions A and C held. The re-tuned stateless constructor solves more
often than the recalibrated feedback variant with inherited weights, so most
of the +20.63-point gain was feedback compensating for poorly weighted
heuristics. On top of re-tuned weights, the recalibrated feedback values add
+4.55 points, an interval that reaches past the band; α and z were not
re-tuned for the new heuristic scale.

## Equal-effort search for the full arm (dev), and a third plan

`tune.py --arm full` gives the full arm the same 48 weight candidates, each
with a random α (0.1–4, log scale) and z (0–0.5), on the same dev puzzles and
seeds. Its best candidate (`out/tune-full/search.json`) reuses the weights of
the frozen winner with α = 1.167 and z = 0.362, and solved 0.748 of dev runs
against 0.698 for the frozen winner; the unchanged configuration solved 0.484.

### Third held-out plan (fixed before the run)

On the 200 train puzzles and seeds 0–29, run `full-joint` (that candidate) and
compare it with `frozen-tuned`. Prediction: a positive point estimate whose
interval is not wholly above +5 points (not *helpful*).

```bash
uv run python -m experiments.feedback_sweep.run --split train --variants full-joint
```

### Third held-out result (train)

| Comparison | Full | Frozen | Difference, points (95% interval) | Classification |
|---|---:|---:|---:|---|
| full-joint vs frozen-tuned | 0.749 | 0.711 | +3.85 (+2.38, +5.42) | inconclusive |

The prediction held. With equal search effort for both arms, feedback adds
about four points, consistent with the +4.55 of the recalibrated values on
re-tuned weights.
